# 使用增益（同输入 · 同模型 · 真跑对照）

同一份材料（1 篇 2 页 PDF）：**A = 不加载 Skill**（qwen4-max 直接要求给"主线+页级主张+图表引用"）；**B = 本 Skill**。
A 的原始回答在 `example/baseline.txt`。

| 指标 | A（无 Skill） | B（有 Skill） |
|---|---|---|
| 研究主线 | 有（但自称 "question is inferred"，把推断写进产物） | 有；**找不到就写 `not found in the material`**，不把推断当材料 |
| 页级主张 | 无（回答只有主线，没有逐页主张） | 5 条，每条带 `文件#页句` 定位符 |
| 图表引用 | 无 | 单列一页，引用句 + 定位符 |
| 可编辑产物 | 无（一段 JSON） | `deck.pptx`（11 页，可编辑）+ `deck.pdf` + **11 张逐页 PNG** |
| 渲染可核验 | 无 | `SELFCHECK.render_status = "rendered 11 page(s)"`，预览即证据 |
| 模板声明 | 无 | `result.template`（16:9 / 标题+要点 / 页脚含 case_id 与定位符） |

**结论（照实写）**
1. A 能把主线读出来，但**交付不出"可编辑 + 可渲染 + 逐页可回原文"的产物**——这正是本题（生成与编辑）的评分重心。
2. B 的增益在：页级主张可追溯、图表引用单列、11 页真渲染预览、模板与页脚一致性。
3. **没有改善的地方**：图内数值不抽（只引正文引用句）；Question 找不到时只标注不推断，可能少于评审期望。
