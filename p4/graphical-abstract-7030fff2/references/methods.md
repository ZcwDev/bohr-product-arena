# 方法与判据

## 本题的工作流程

1. 提炼一句话核心信息（≤20 词）与三段式要素（背景/方法/结果+意义），每条对应材料定位符。
2. 构图：左→右或上→下三段，主信息占视觉焦点；用 `figure.py diagram` 的节点/箭头表达流程，避免装饰性元素。
3. 文字控制：图内标签总计 ≤ 60 词；缩写首次出现给全称；不出现正文才能解释的符号。
4. 合规：目标期刊尺寸（宽×高 mm 或 px）、分辨率（≥300dpi）、字体（≥7pt 等效）、颜色无障碍（避免红绿对立为主要区分手段）。
5. 导出 TIFF/PNG（≥300dpi）+ PDF 矢量 + 可编辑源（svg）；`compliance_checks` 写尺寸/分辨率/字体/配色的实测值。
6. result.json 记录核心信息与每个视觉元素对应的证据定位符。

## 交付前自检清单

- 核心信息唯一且 ≤20 词
- 三段式齐全
- 图内文字 ≤60 词
- 尺寸/分辨率/字体实测合规
- 配色不依赖红绿对立
- 每个元素可回溯

## 定位符约定

- PDF：`p<页>b<块>`（块号在同一页内从 1 递增，由 `pdf_text.py` 生成）
- 纯文本：`<文件名>:<行号>` 或 `<文件名>:<段落号>`
- 代码/配置：`<文件>:<行号>`
- 引语核验：`evidence.py verify blocks.json quotes.json`，`exact=true` 才可作为逐字证据
