# 方法与判据

## 本题的工作流程

1. 拆题面要求为论断清单（`claims_plan.jsonl`），每条标注需要的证据类型与强度。
2. 为每条论断找证据（`evidence.py locate`），记录 locator + 逐字 quote + 该证据的适用条件。
3. 写正文：论断句 → 证据句（带引用）→ 限制句（条件/反例/证据强度）；证据不足时把语气降级（suggest/可能）并在 `limitations` 说明。
4. 反向检查：对正文逐句跑 `text_checks.py claims`，没有引用支撑的句子必须改写或删除。
5. 引用一致性：正文引用标记与参考文献列表一一对应，无孤儿条目、无未列出的引用。
6. 输出 `result.json`：evidence_map 覆盖每条论断，change_log 记录降级与删除动作。

## 交付前自检清单

- 每条论断有定位符级证据
- 证据不足处已降级而非硬写
- 引用双向一致
- 限制条件随证据带出

## 定位符约定

- PDF：`p<页>b<块>`（块号在同一页内从 1 递增，由 `pdf_text.py` 生成）
- 纯文本：`<文件名>:<行号>` 或 `<文件名>:<段落号>`
- 代码/配置：`<文件>:<行号>`
- 引语核验：`evidence.py verify blocks.json quotes.json`，`exact=true` 才可作为逐字证据
