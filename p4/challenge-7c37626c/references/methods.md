# 方法与判据

## 本题的工作流程

1. 抽取：从 PDF 文本块与渲染图里定位公式（`type=equation` 或包含 `=` 且符号密度高的块），记录 `p<页>b<块>` 与公式编号。
2. 符号表：为每个符号建立 `symbol -> {definition, unit, source_locator}`；材料未定义 → `undefined_in_source`，不要沿用常见约定。
3. 渲染对照：用 `pdf_render`（或 `pdf_text.py extract` 的残页）截出公式所在页的图片块，供人工核对上下标与希腊字母。
4. 重排：把公式写成显式文本形式（保留括号层级），上下标用 `_`/`^` 标注，避免 Unicode 近似字符导致失真。
5. 推理：只在给定条件下做符号或数值推导，每步写出所用前置公式编号与本步变换类型；数值代入给出单位与有效数字。
6. 自检：量纲一致性、极端值/退化情形、与原文结论是否方向一致；不一致就报 `conflict` 并停在冲突处。

## 交付前自检清单

- 每个公式有编号与定位符
- 符号定义可回溯到原文
- 推导每步可复算
- 量纲检查已做
- 未定义符号未按常识补定义

## 定位符约定

- PDF：`p<页>b<块>`（块号在同一页内从 1 递增，由 `pdf_text.py` 生成）
- 纯文本：`<文件名>:<行号>` 或 `<文件名>:<段落号>`
- 代码/配置：`<文件>:<行号>`
- 引语核验：`evidence.py verify blocks.json quotes.json`，`exact=true` 才可作为逐字证据
