# 使用增益（同输入 · 同模型 · 真跑对照）

同一份材料（2 页论文 PDF + 4 个目标字段）：
**A = 不加载 Skill**（材料与字段表直接交给 `qwen4-max`）；**B = 加载本 Skill**（`scripts/extract_fields.py`）。
A 的原始输出在 `example/baseline_fields.txt`，B 的在根 `result.json`。

| 指标 | A（无 Skill） | B（有 Skill） | 变化 |
|---|---|---|---|
| 正确抽到的字段 | **1 / 4**（只有 F1） | **3 / 4**（F1、F2、F4） | **+2** |
| 误报不存在 → `not_reported` | 3（把 F2/F4 判成未报告，实际原文有） | 1（只有 F3 真未报告） | 漏检 −2 |
| 可机检定位符（`p{页}b{块}`） | **0 / 4** | **3 / 4**（F3 无证据故无定位） | +3 |
| 空效应（"no significant change"）能否算已报告 | 否（判 not_reported） | 是（`reported` + `qualifier`） | 新增 |
| 治疗 vs 对照同句（312 vs 615）是否误判冲突 | 未处理 | 明确不算冲突（只在跨块不同值才算） | 新增 |

**结论（只写实测）**
1. **召回**：A 漏了 IC50（12 nM，在 Methods 段）和体重变化（空效应），B 都抽到了；这是本题最直接的质量差异。
2. **可核验性**：A 的定位是"Abstract, sentence 3"这类散文描述，0 条能程序化回原文；B 3 条带 `p{页}b{块}`。
3. **单位纪律**：两边单位都对（mm3/nM/%），但 A 对未抽到的字段仍填了单位（`nM`/`%`），容易让人误以为已抽到。
4. **没有改善的地方**：字段仍依赖关键词词表；若原文用同义表述（如 "half-maximal inhibitory concentration"），
   可能需要人工补词；图内数值不抽。
