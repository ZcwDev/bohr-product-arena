# 使用增益（同输入 · 同模型 · 真跑对照）

同一组输入（题集 + 候选答案 + 参考变体 + 双评记录）：
**A = 不加载 Skill**（直接交给 LLM 要求打分 + 一致性）；**B = 本 Skill**。

| 指标 | A（无 Skill） | B（有 Skill） |
|---|---|---|
| 逐题分数 | 可能给出归一化分数（0–1），无权重解释 | 按 rubric 权重加权求和，每条判据有 `score` + `why` |
| 失败类型 | 可能给出标签（如 `missing_section`） | 有完整分类（`wrong_fact`, `wrong_format`, `style_or_variant`, `missing_output`, `empty_output`）+ 每条锚点的 `why` |
| 一致性统计 | 可能算出 κ，但不标注退化情况 | 同值，且对 n<2 的判据显式给 `null`，标注 `agreement_computed` |
| **每条判据的扣分理由** | **无**（只有失败标签或笼统描述） | **有**（`criteria[].why`：缺哪一节 / 命中哪个 reject 片段 / 未匹配 accept） |
| **可追溯（输入哈希）** | **无** | 有（`run_record.inputs_sha256_16`，逐文件记录） |
| **可复跑产物** | **无**（一段回答） | `result.json` + `per_item.tsv` + `report.md` + `SELFCHECK.json` |
| 改进建议 | 无或笼统（"改进准确性"） | 有（逐题："补上缺失小节" / "对照参考变体重写该处" + 低 κ 锚点需改） |
| 题集派生 | 无（需要人工出题） | 有（从材料自动派生，含事实/数值的句段 → 写作题） |

**结论（照实写）**
1. **A 的判定与一致性统计在小样本上可能并不比 B 差**——所以增益不在"算得对"，而在
   **每条分数的可解释性（锚点级 why）、可追溯（哈希）、可复跑（产物）与改进建议**。
2. B 把"kappa=0"直接翻译成"该锚点不可观察，应改锚点而不是改分数"——这是 A 不会给出的动作。
3. B 在**无题集**时能从材料派生题集（`derive_items`），A 需要人工出题。
4. **没有改善的地方**：语义级判断（事实是否真的与引用一致）两边都要靠人；本工具只做锚点级结构匹配。
