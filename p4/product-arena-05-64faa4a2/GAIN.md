# 使用增益（同输入 · 同模型 · 真跑对照）

同一份材料（1 篇 2 页 PDF）：
**A = 不加载 Skill**（把材料直接交给 `qwen4-max`，要求写 IMRaD 稿件）；**B = 本 Skill**。
A 的原始回答在 `example/baseline.txt`。

| 指标 | A（无 Skill） | B（有 Skill） |
|---|---|---|
| 稿件形态 | 一段 Markdown 回答 | `manuscript.md` + **`manuscript.docx`（真 OOXML：6 部件 / Title+Heading1 样式 / 编号 / `w:tbl` / `TOC` 域）** |
| 每条断言的定位 | **0 条机器可查**（散文式引用） | **11 条**（`claim_source_map.tsv`：`S# → 文件#页码句号 → 原文引句`） |
| 输出里的数字能否回到材料 | 12 个数字中 **3 个无法在材料原文里对齐**（`0`/`49`/`51`，来自 p 值/编号的模糊转写） | 全部**整段抄录**（`312 ± 41 mm3` 取 312 mm3，含单位） |
| 缺失章节的处理 | 未显式标注 | 逐节写「〔待补：材料中未找到该章节的事实依据〕」并进 `review_checklist.md` |
| 可编辑性 | 只有回答文本 | `.docx` 保留标题层级/编号/表格，可在 Word 继续改；`.md` 同步 |

**结论（照实写）**
1. A 的**文笔不差**，但它给不出"每条断言回哪里、哪个数字来自哪句"——评审无法复核，这是本任务的核心失分点。
2. B 的增益集中在**可核验 + 可编辑**：11 条断言-来源映射、真 OOXML 交付、缺章节显式标注。
3. **没有改善的地方**：B 的正文只复述材料，论证性写作弱于 A；材料口径冲突时不替裁判，只标出来。
